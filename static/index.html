当前汇总

由已提交的增量批次累积而来。每个分组同时给出订单数、非空金额笔数、空金额笔数、零金额笔数、金额合计与客单价。

区域状态

「无分组」表示该区域已没有任何销售；「合计为零」表示区域仍有销售，但非空金额合计为 0.00。两者不能混同。

各区域金额合计

只画金额合计一个量；订单数与客单价在右侧表格与悬浮提示中。

分组明细

客单价 = 金额合计 ÷ 非空金额笔数；没有非空金额时为「未定义」，不是 0。

源表

销售与门店都是虚构样例，可直接在本页修改。改动先进入「待提交变更」，提交后才进入增量批次，汇总不会因编辑而提前变动。

新增销售

金额留空表示空值；填 0 表示一笔金额为零的真实销售。门店可以选未分配区域的门店或留空，它们会进入「未匹配」分组。

销售源表

修改金额或门店会生成一条 update 操作；删除会生成 delete 操作。提交时每条 update 都先撤回旧贡献，再加入新贡献。

门店资料

改变门店区域会产生一次整店迁移：该店每条有效销售都会先撤回旧区域，再加入新区域。

待提交变更 0

这些操作还没有进入增量汇总。也可以到「批次与场景」标签页用 JSON 编辑器提交。

批次与场景

每个批次就是一个增量批次：它的操作明细、签名增量、结果汇总与全量对照一起提交。相同内容重复提交只会被识别为幂等重放，不会二次累计。

批次编辑器

载入场景后可自由改写：改金额、改门店、增删操作、切换 strict、设置故障注入点。

提交结果

提交后这里显示批次状态、被拒收的操作、逐区域撤回/加入/净值。

还没有提交过批次。载入场景或编辑源表后提交，这里会给出结果。

批次历史

点击「明细」查看该批次的操作与区域增量；点击「重放」用同一内容再次提交，验证不会重复累计。

单条变更的影响

选择某个批次里的某一条操作，查看它撤回与加入了哪些分组，以及该分组在这次变更前后的数值。

选择变更

只在已提交的批次里选择。operation 的索引从 0 开始。

对照与审计

对某个快照，重新用该快照自己的源表数据完整重算一遍，与持久化的增量汇总逐区域、逐指标对照；同时保留失败与回滚的审计记录。

尝试记录

失败与被回滚的批次不会出现在批次历史里，但这里保留它们：失败在事务内发生，源表和汇总都没有被改动。

重置本地数据

删除当前数据库并重新写入虚构样例。仅影响本机文件，不影响任何远程系统。
